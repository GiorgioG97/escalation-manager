⚙ Configurazione Storage

I dati vengono salvati su JSONBin.io — gratuito, senza backend. Crea un account su jsonbin.io e segui i passaggi.

1Crea un Bin

Vai su jsonbin.io/app/bins → clicca Create Bin → incolla [] come contenuto iniziale → salva.

Es: 64f3a2b7c4d5e6f7a8b9c0d1
2API Key

Account → API Keys → copia la chiave Master Key o una chiave con permessi di lettura/scrittura.

Salvata solo nel tuo browser (localStorage).
